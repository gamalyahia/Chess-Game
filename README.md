# Chess Game ♟️

A desktop-based Chess Game developed using C# and WPF, implementing the complete rules of chess with a clean and interactive user interface.

## Features

* Full implementation of chess rules
* Valid move validation for all pieces
* Turn-based gameplay system
* Check and Checkmate detection
* Draw conditions handling
* Interactive graphical user interface
* Game state management

## Tech Stack

* C#
* WPF (.NET)

## Project Structure

The project follows Object-Oriented Programming principles and uses classes to represent:

* Chess Board
* Pieces
* Players
* Game Logic
* Move Validation

## Learning Outcomes

Through this project, I gained hands-on experience in:

* Object-Oriented Programming (OOP)
* Design and implementation of game logic
* State management
* Problem-solving and algorithmic thinking
* Desktop application development with WPF
